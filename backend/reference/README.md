# Reference snapshots

This folder holds **read-only copies** of upstream design and architecture material for DX-LAB. They are **not** imported at runtime.

- **`dx_lab_architecture/`** — snapshot of the `architecture/` tree from the DX-LAB-architecture repo. Use it for documentation and comparison only.

For product behavior and the live ACP hub, edit **`acp_hub/`** in this repo instead of editing files here.
